# Security

## Reporting a vulnerability or credential exposure

Please report suspected vulnerabilities or accidental credential exposure privately through [GitHub's private vulnerability reporting for this repository](https://github.com/leocavalcante/pi-tmux/security/advisories/new). Do not include credentials, API keys, access tokens, exploit details, or private data in a public issue or pull request.

If a credential has been exposed, revoke or rotate it with its provider. Do not post the credential itself in a report.
